# LinuxEssentials

A comprehensive laboratory for mastering Linux internals, performance monitoring, and advanced command-line proficiency, curated for SRE and DevOps engineering workflows.

---

## 📚 Overview

**LinuxEssentials** is a hands-on learning repository designed for Site Reliability Engineers (SREs) and DevOps practitioners who want to deepen their Linux expertise. Each module is structured as a self-contained lab with exercises, cheat-sheets, and practical examples that reflect real-world operational scenarios.

---

## 🗂️ Repository Structure

```
LinuxEssentials/
├── 01-search-navigation/    # File system navigation and search techniques (find, locate, fd, fzf)
├── 02-vim-mastery/          # Vim/Neovim workflows, plugins, and productivity tips
├── 03-resource-monitoring/  # CPU, memory, disk, and network monitoring tools (top, htop, vmstat, iostat, etc.)
├── 04-system-management/    # User management, systemd, cron, permissions, and package management
└── scripts/                 # Reusable shell scripts and automation helpers
```

---

## 🎯 Learning Objectives

| Module | Topics |
|--------|--------|
| **01 – Search & Navigation** | `find`, `locate`, `fd`, `fzf`, `tree`, `pushd/popd`, globbing |
| **02 – Vim Mastery** | Modal editing, macros, registers, plugins (vim-plug/lazy.nvim), `.vimrc` tuning |
| **03 – Resource Monitoring** | `top`, `htop`, `vmstat`, `iostat`, `sar`, `dstat`, `nethogs`, `ss`, `lsof` |
| **04 – System Management** | `systemd`, `cron`, user & group management, file permissions, package managers |
| **scripts** | Automation scripts for common SRE/DevOps tasks |

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/leandrocarpenter/LinuxEssentials.git
cd LinuxEssentials

# Browse a module
ls 01-search-navigation/
```

Each module directory contains its own `README.md` with instructions, exercises, and references.

---

## 🛠️ Prerequisites

- A Linux environment (bare-metal, VM, WSL2, or Docker container)
- Bash 5+ or Zsh
- Basic familiarity with the command line
